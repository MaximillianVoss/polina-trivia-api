## Быстрый запуск

Нужен Node.js 24 (проверено на 24.19.0).

```bash
cd "/путь/к/комплекту/projects/frontend/trivia-api"
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. Остановка — Ctrl+C.

```bash
npm test
npm run build
npm run preview
```

API-ключ не нужен. Запрос появляется только после нажатия кнопки. При ограничении частоты подождите минимум 5 секунд; общий IP может использоваться и другими пользователями.
